# Bsale Airline API

API REST desarrollada en Python con FastAPI para simular el check-in automático de pasajeros de Andes Airlines.

## Tecnologías utilizadas

- Python
- FastAPI
- PyMySQL
- MySQL
- Uvicorn
- Python-dotenv
